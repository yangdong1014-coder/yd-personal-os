# PSY Agent Instructions

Before modifying this repository:

1. Identify whether the task involves Development, UI, Database, AI, Release, or Documentation.
2. Read `docs/standards/README.md` and the applicable standards it routes to.
3. Resolve document conflicts using the `Rule Precedence` section in that index.
4. Apply the applicable Definition of Done before declaring completion.
5. Include a `Standards Applied` section in the final delivery report.

Required entry points:

- `docs/standards/DEVELOPMENT.md`
- `docs/standards/UI.md` when changing UI
- `docs/standards/DATABASE.md` when changing data or schema
- `docs/standards/AI.md` when changing AI features
- `docs/standards/RELEASE.md` when releasing
- `docs/standards/DEFINITION_OF_DONE.md` before declaring work complete

Subdirectory `AGENTS.md` files may add stricter local rules but cannot weaken this file.
